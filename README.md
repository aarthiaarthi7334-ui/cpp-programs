# C++ Programming Projects

This repository contains three C++ programs based on Data Structures.

## Programs

### 1. Linked List

A C++ program that demonstrates inserting coaches at the beginning and end, removing a coach, and displaying the linked list.

### 2. Car Parking

A C++ program that uses a stack to manage cars entering, leaving, and being displayed in a parking area.

### 3. Website

A C++ program that demonstrates browser history using a stack and simulates the Back operation.

## Files

* `linkedlist.cpp`
* `carparking.cpp`
* `website.cpp`

## Language

**C++**

These programs were created for practicing Data Structures and C++ programming.
